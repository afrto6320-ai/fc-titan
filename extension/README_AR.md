# CODEX SNIPE 3.4.2

## التثبيت
عطّل الإصدار السابق، وفك ضغط CODEX_SNIPE_v3.4.2.zip، ثم Load unpacked للمجلد الذي يحتوي manifest.json. حدّث صفحة Web App بالكامل لتحميل سكربت MAIN الجديد.

## ما تغير
- أول بحث عن لاعب يتصل بمحرك EA المحلي تلقائيًا. عند فشل الاتصال يظهر الخطأ؛ لا تتحول الواجهة خفية إلى مصدر آخر.
- اختيار لاعب من الاقتراحات يستخدم السجل الذي أعادته EA وtoken خاص بالقائمة، بدل إعادة البحث باسمه الكامل. بعض محركات EA تطابق النص القصير وتفشل مع الاسم الكامل.
- اختيار بطاقة كتالوج قديمة يميز Item ID للنسخة عن Player ID الأساسي. عند توفر ItemIdMask.DATABASE في EA يطبّق قناع اللعبة الأصلي، ثم يطلب مطابقة ID مؤكدة من محركها. مثال الاختبار: 50540979 -> 209331. يظل Item ID للنسخة محفوظًا لفحص النتائج.
- Start يعيد تأكيد اللاعب تلقائيًا قبل العمل، وحالة التأكيد لا تظل خضراء لاختيار قديم أثناء التحقق من الجديد.
- اختيار لاعب جديد يستبدل الهدف النشط. المحرك الحالي يعمل بهدف واحد؛ لا يدّعي تشغيل بحث متعدد.
- صور اللاعبين الأساسية تستخدم AssetLocationUtils.getPortraitImageUri. إنها صور اللاعب الأساسية، وليست معاينة كاملة لكل نسخة بطاقة.
- كشف أسماء الترجمة الناقصة يدعم النجمة السابقة للمفتاح وعلامات اتجاه الكتابة. الخيارات غير المترجمة مخفية افتراضيًا، ويمكن إظهارها بالـID مع وسم واضح.
- اسم النادي المتشابه يظهر في مجموعة واحدة. افتحها لتختار الدوري والـID الفعلي؛ لا تُحذف الاختيارات المختلفة ولا تُستبدل هوية نادي بهوية آخر.
- شعارات الفلاتر تستخدم جدول EA وgenerateFilterImage ودوال badge/league/flag الأصلية المتاحة. عند فشل الصور يظهر مؤشر غير متاح؛ لا تُركب شعارات تخمينية.

## طريقة التجربة
1. افتح CODEX SNIPE واكتب جزءًا من اسم اللاعب.
2. انتظر ظهور EA native وصورة اللاعب الأساسية عند توفرها، ثم اضغط نتيجة واحدة.
3. تأكد من ظهور EA player ID مؤكد، واختر الندرة/الحدث من فلتر EA.
4. أدخل Max Buy Now والميزانية وحد بحث صغيرًا مثل 2، واترك Auto Buy متوقفًا في الاختبار الأول.
5. Start يعد الردود المؤكدة بما فيها الرد الخالي. Stop يفصل انتظار الرد ويمنع الجولة التالية؛ الطلب الذي أرسلته EA بالفعل قد يكتمل في اللعبة.

## مصدر البيانات وحدودها
الفلاتر واختياراتها بالـID تأتي من EA. وجود خيار لا يثبت وجود عروض له حاليًا ولا أن كل أحداث اللعبة متاحة في القائمة. الكود القديم لكتالوج FUT.GG موجود للتوافق مع مسار DOM/الاختبارات، لكن المسار الافتراضي في الحزمة الحديثة هو EA.
الصور الأصلية قد تكون مفقودة على خوادم EA لبعض السجلات الداخلية. المجموعة تعرض مختلف IDs بالاسم نفسه، ومنها دوري عادي ودوري داخلي، دون افتراض أنها نفس هوية السوق.
الشراء الآلي لا يزال تجريبيًا؛ يحتاج ربط العرض بصف وحيد في واجهة الشراء وتأكيد السعر. لم تختبر هذه النسخة شراءً حقيقيًا أو تشغيلًا حيًا على حساب EA.

## الفحوص
```
node --test tests/*.test.cjs
python tests/page_functions.py
python tests/features_v33.py
python tests/native_navigation.py
```
اختبار page_functions يحتاج FC_EA_SOURCE_DIR الذي يشير إلى js الملتقط من EA، وPlaywright وChromium. الملفات الأصلية وبيانات الحساب غير مرفقة بالمستودع. الاختبارات تستخدم صفحة محاكاة وسياقين منفصلين MAIN/ISOLATED مع بعض معالجات EA المستخرجة من المصدر، ولا تثبت إتمام شراء حي.
